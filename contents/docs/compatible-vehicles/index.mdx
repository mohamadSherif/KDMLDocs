## Compatible Vehicles

KDMLink is built for supported Hyundai N vehicles. Check this list before installing the
**N-Link** hardware or pairing the app.

## Supported N cars

| Vehicle | Notes |
| --- | --- |
| Hyundai Veloster N | Plug and play. |
| Hyundai Elantra N | Wire tap method. |
| Hyundai Kona N | Plug and play. |
| Hyundai i20 N | Coming soon. |
| Hyundai i30 N | Coming soon. |
| Hyundai i30 Fastback N | Coming soon. |
| Hyundai IONIQ 5 N | Coming soon. |
| Hyundai IONIQ 6 N | Coming soon. |

N Line trims are not the same as full N vehicles. If your car is an N Line model, confirm
support before installing.

## Requirements

- KDMLink **N-Link** interface
- KDMLink app on iPhone or Android
- Supported Hyundai N vehicle
- Correct N-Link install method for your vehicle

## Install methods

- [**Plug and play**](/docs/installation/n-link/plug-and-play) — for supported vehicles where
  the N-Link can connect directly at the OBD-II port.
- [**Wire tap**](/docs/installation/n-link/wire-tap) — for supported vehicles that require
  tapping the correct signal and power wires for a clean N-Link connection.
